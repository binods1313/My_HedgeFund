# Getting Started

## Prerequisites

- Node.js >= 18
- Python 3.11+
- Redis 7+

## Installation

```bash
# Clone the repository
git clone https://github.com/your-organization/hedgefund.git

# Navigate to the project
cd hedgefund

# Install dependencies
npm install
```

## Quick Start

```bash
# Start the development server
npm run dev
```

Visit `http://localhost:3000` to see the application.
